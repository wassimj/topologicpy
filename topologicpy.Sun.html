static Diagram(latitude, longitude, minuteInterval=30, dayInterval=15, origin=None, radius=0.5, uSides=180, vSides=180, north=0, compass=False, shell=False, *, year=None, timeZone='UTC')

Returns the sun diagram based on the input parameters. See https://hyperfinearchitecture.com/how-to-read-sun-path-diagrams/.

Parameters
latitudefloat

The input latitude. See https://en.wikipedia.org/wiki/Latitude.

longitudefloat

The input longitude. See https://en.wikipedia.org/wiki/Longitude.

minuteIntervalint , optional

The interval in minutes to compute the sun location for the date path. Default is 30.

dayIntervalint , optional

The interval in days for the hourly path to compute the sun location. Default is 15.

origintopologic_core.Vertex , optional

The desired origin of the world. If set to None, the origin will be set to (0,0,0). Default is None.

radiusfloat , optional

The desired radius of the sun orbit. Default is 0.5.

uSidesint , optional

The number of sides to divide the diagram horizontally (along the azimuth). Default is 180.

vSidesint , optional

The number of sides to divide the diagram paths vertically (along the altitude). Default is 180.

northfloat, optional

The desired compass angle of the north direction. Default is 0 which points in the positive Y-axis direction.

compassbool , optional

If set to True, a compass (shell) is included. Othwerwise, it is is not.

shellbool , optional

If set to True, the total surface (shell) of the sun paths is incldued. Otherwise, it is not.

Returns
dict

A dictionary of the sun diagram shapes. The keys in this dictionary are: ‘date_paths’: These are the sun paths (wire) for the winter solstice, equinox, and summer solstice ‘hourly_paths’: These are the figure-8 (wire) for the sun location on the same hour on each selected day of the year. ‘shell’: This is the total surface (shell) of the sun paths. This is included only if the shell option is set to True. ‘compass’: This is the compass (shell) on the ground. It is made of 36 sides and 10 rings. This is included only if the compass option is set to True. ‘center’ : This is a cross-shape (wire) at the center of the diagram. This is included only if the compass option is set to True. ‘ground’ : This is a circle (face) on the ground. It is made of 36 sides. This is included only if the compass option is set to False.

static EventsByDate(latitude, longitude, date, *, timeZone='UTC', elevation=0, pressure=101325, temperature=15, horizon=0, useCenter=False)

Rising/setting events INSIDE one civil date in the specified zone.

Output events and day bounds are aware datetimes in that zone. Sunrise and sunset may occur in either order in a UTC civil day. They must not be independently paired as a daylight duration. daylightIntervals gives clipped, correctly paired intervals, including midnight-spanning light. status is normal, polar_day, polar_night, or transition (one event). Defaults use the apparent upper limb at horizon=0, matching ephem’s event convention. useCenter=True selects the solar centre. PositionData aboveHorizon instead refers to the solar centre; it is a distinct test.

static PositionsByDates(latitude, longitude, dates, north=0, *, engine='ephem', elevation=0, pressure=101325, temperature=15, timeZone=None, apparent=True)

Numeric records at explicit instants; no geometry objects are created.

Latitude is -90..90; east longitude -180..180. elevation is metres, pressure Pa, temperature Celsius. Naive datetimes mean UTC unless an explicit timeZone is supplied. Output timestamps are aware UTC. engine is explicitly ‘ephem’ or optional ‘pvlib’; no implicit fallback. Azimuth is geographic clockwise from north. Vectors are model XYZ, +Z up, model north rotated clockwise from +Y by north degrees. Apparent elevation includes refraction; geometric elevation does not. toSun/fromSun use the selected elevation and have unit length without display rounding. All callers should share this same record series.

static SkyPatches(azimuthDivisions=36, altitudeDivisions=12, north=0)

Equal-solid-angle upper-hemisphere patches, sampled at mu midpoints.

mu=sin(altitude); patch solidAngle is steradians. Directions are model space. These are quadrature patches, not a named standard sky basis.

static SkyVisibility(points, normals, scene, *, azimuthDivisions=36, altitudeDivisions=12, north=0, **kwargs)

Return patch visibility and projected sky-view factors.

skyViewFactor=sum(visible * max(n dot direction,0) * solidAngle)/pi. An unobstructed upward surface is 1, a vertical surface approximately 0.5, and a downward surface 0. Ground reflection is excluded. Patch solid angles and weights are retained for anisotropic sky integration; this method itself assumes uniform sky radiance. Refine divisions for convergence. Visibility can be reused while geometry is unchanged.

static SolarAccess(points, normals, positions, scene, durations=None, *, timeEdges=None, areas=None, **kwargs)

Integrate point sunlight hours, with explicit interval durations.

Supply either durations in seconds (one per position), or N+1 aware/ UTC timeEdges. Positions must lie inside their respective intervals. Duration weights are NOT inferred from drawing paths or treated as cosine weights. This is geometric sunlight duration, not irradiation. Optional positive cell areas give an area-weighted mean, not XY area. Zero-duration endpoint samples are allowed. Total duration must be >0.

static VerticesByDate(latitude, longitude, date, startTime=None, endTime=None, interval=60, origin=None, radius=0.5, north=0, *, timeZone='UTC')

Time-sampled sun vertices, including exact interval endpoints.

With no start/end, sample the civil day’s daylight intervals; polar night returns []. Explicit bounds include nighttime and denote instants. Endpoint vertices are drawing samples, not integration weights.

static VerticesByHour(latitude, longitude, hour, startDay=1, endDay=None, interval=5, origin=None, radius=0.5, north=0, *, year=None, timeZone='UTC')

Sun vertices at numeric civil hour [0,24), inclusive day range.

year defaults to the current year; endDay defaults to 365/366. An exact endDay sample is appended when spacing does not divide the range. Ambiguous/nonexistent DST wall-clock times raise; use explicit dated instants with PositionsByDates when a fixed civil hour is ambiguous.

static Visibility(points, normals, positions, scene, *, batchSize=4096, minDistance=None, maxDistance=inf, maxPairs=10000000, cancelled=None)

Geometric sun visibility for receiver XYZs/normals and position records.

Returns uint8 states shaped (receivers,times): 0 visible, 1 occluded, 2 back-facing, 3 below horizon (precedence: horizon, back-facing, hit). Points and normals are paired; a single normal broadcasts. Model-space directions come from toSun, with no implicit sign conversion. Explicit numeric directions must first be wrapped as records with toSun and aboveHorizon. This is point sampling, not panel electrical shading. Work is chunked; maxPairs bounds the materialized output. The caller supplies receiver cell areas and integration durations separately.
