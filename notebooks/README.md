# Notebooks

For the ordered, beginner-friendly TopologicPy **0.9.86 / pythonocc** learning sequence, start with [tutorials/README.md](tutorials/README.md).

The numbered notebooks in `tutorials/` are the maintained tutorial entry point. Existing notebooks in this directory are retained as legacy examples and research/workshop material. Their names, outputs and APIs do not establish compatibility with the tested environment.

See [NOTEBOOK_AUDIT.md](NOTEBOOK_AUDIT.md) for the inventory, limitations and migration decisions, and [tutorials/verification.md](tutorials/verification.md) for actual execution evidence.
