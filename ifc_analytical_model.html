Analytical spatial models from IFC

IFC analytical spatial models

IFC.AnalyticalModel reconstructs simplified spatial volumes using evidence strictly descended from an IFC building and storey. It returns one verified CellComplex per usable building and reports approximate room and boundary fidelity. The result is a geometric approximation, not an energy simulation.

from topologicpy.IFC import IFC

result = IFC.AnalyticalModel("building.ifc", coordinateFrame="local")
for building in result.building_models:
    print(building.building_id, building.statistics, building.diagnostics)

The input can be an IFC path or IFCModel. coordinateFrame accepts local or world (the default). Native geometry closure and shared-face verification are always performed; verify is accepted for API compatibility.
